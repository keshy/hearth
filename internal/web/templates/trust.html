Mac

  1. Open the downloaded file. Keychain Access adds it to the login keychain.
  2. Double-click Caddy Local Authority, expand Trust, and set When using this certificate to Always Trust.

iPhone and iPad

  1. Open this page in Safari, tap Download certificate, then Allow.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings → turn on Caddy Local Authority.

Android

  1. Download the file.
  2. Settings → Security → More security settings → Encryption & credentials → Install a certificate → CA certificate. Menu names vary by phone.

Windows

  1. Open the downloaded file → Install Certificate → Local Machine.
  2. Choose Place all certificates in the following store → Trusted Root Certification Authorities.

Firefox

Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import, then tick “Trust this CA to identify websites”.
